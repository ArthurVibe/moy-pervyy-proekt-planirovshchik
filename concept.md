# What's Up, Bro? — концепция первого прототипа

## Цель

Сделать простой персональный планировщик в браузере, чтобы проверить основной сценарий: записать задачу, назначить срок, выполнить её и вернуться к сохранённому списку позже.

На начальном этапе нужен прототип для тестирования. Расширенные возможности из Roadmap v4.0 отложены. Этот документ описывает сокращённый объём первой версии и имеет приоритет перед дорожной картой при её реализации.

## Формат

- Одна веб-страница: `index.html`, `style.css`, `script.js`.
- Обычные HTML, CSS и JavaScript, без фреймворков, сборки и внешних библиотек.
- Все данные сохраняются в localStorage браузера.
- Нет серверной логики, базы данных, регистрации, API и внешних запросов.
- Приложение предназначено для одного человека в одном браузере.

Первичный способ проверки — открыть `index.html` в браузере. Для этого JavaScript подключается обычным скриптом, без модулей и загрузки локальных ресурсов через fetch. Поведение localStorage при открытии через `file://` зависит от браузера; его нужно проверить на целевом устройстве. При необходимости можно использовать статический хостинг: он только отдаёт три файла, данные остаются в браузере. Автоматического переноса данных между локальным файлом и веб-адресом нет.

## Первая версия

Один экран со списком задач и компактной формой добавления. Рабочее допущение для простого прототипа: ввод ручной, без разбора естественного языка.

Пользователь может:

1. Добавить задачу с обязательным названием и необязательными датой и временем.
2. Изменить название, дату или время существующей задачи.
3. Отметить задачу выполненной и вернуть её в работу.
4. Удалить задачу с подтверждением.
5. Закрыть страницу и при следующем открытии увидеть сохранённые данные.

Дата выбирается обычным полем ввода, без отдельного календарного раздела. Время можно указать только вместе с датой. Если срок не указан, задача сохраняется без него: сегодняшняя дата и время автоматически не назначаются.

Невыполненные задачи показываются первыми и сортируются по дате, затем по времени. Задачи без времени идут после задач со временем в пределах того же дня; задачи без даты — после датированных. При одинаковом сроке используется порядок создания. Выполненные задачи остаются видны внизу списка и визуально отличаются от активных.

Перенос срока выполняется редактированием существующей записи и не создаёт копию задачи. Изменение только даты сохраняет прежнее время. Удаление даты очищает и время.

## Интерфейс

Сохранить название What's Up, Bro?, графитовый фон и зелёные акценты из исходной концепции. Основной акцент — на читаемости и быстрых действиях.

На компьютере и телефоне используется один понятный экран без боковых колонок. Действия доступны кнопками, без обязательного наведения мышью. Для пустого списка показывается короткая подсказка о создании первой задачи. Маскот, анимации и дополнительные экраны пока не нужны.

## Данные и сохранение

Запись задачи содержит: уникальный `id`, название `title`, необязательные `dueDate` и `dueTime`, признак выполнения `completed`, время создания `createdAt` и последнего изменения `updatedAt`.

Дата хранится как `YYYY-MM-DD`, время — как `HH:mm`, без преобразования календарной даты в UTC. В хранилище сохраняется объект с версией схемы `schemaVersion` и массивом `tasks`.

Приложение проверяет структуру прочитанных данных. Пустое название не принимается. Ошибка чтения, повреждённые данные или недоступность localStorage показываются понятным сообщением. Повреждённые данные нельзя автоматически затирать пустым списком. Успешное сохранение подтверждается только после записи в хранилище; при ошибке введённый текст сохраняется в форме для повторной попытки.

Данные принадлежат конкретному браузерному профилю и адресу страницы. Между устройствами они не синхронизируются; очистка данных сайта может удалить список. Прототип предназначен для тестовых записей. Импорт и экспорт добавляются отдельным следующим шагом, прежде чем использовать приложение для важных данных.

## Что откладываем

- AI, OpenAI и ввод команд обычным языком.
- Голосовой ввод и серверный посредник.
- Разделы календаря и заметок, преобразование заметок в задачи.
- Приоритеты, повторяющиеся задачи, массовые действия и drag-and-drop.
- Напоминания, системные уведомления и вечерние обзоры.
- Маскот Hoodie Bro и реакции персонажа.
- Импорт и экспорт JSON, история изменений и отмена действий.
- Синхронизацию, аккаунты, внешние календари, PWA и push.
- React, TypeScript, Tailwind, сборку и сложную инфраструктуру выпуска.

Roadmap v4.0 остаётся источником идей для последующих этапов. Его порядок заданий, архитектура AI и процесс PR не являются обязательствами этого прототипа.

## Критерии готовности прототипа

1. Страница открывается без установки зависимостей и внешних запросов.
2. Создание, редактирование, выполнение, возврат в работу и удаление задач работают.
3. Задача без срока сохраняется без выдуманной даты; сортировка соответствует правилам выше.
4. После перезагрузки страницы сохраняются текст, срок и статус выполнения.
5. Редактирование срока не меняет id задачи и не создаёт дубликатов.
6. Пустой ввод и ошибки хранилища обрабатываются без ложного сообщения об успехе.
7. Интерфейс удобен на ширине телефона и компьютера.

После реализации проверить эти сценарии вручную в браузере пользователя. Этот документ не утверждает, что приложение уже создано или проверено.

## Текущий этап

Согласована простая браузерная версия для тестирования; остальные возможности отложены. Сохранена концепция. Код приложения и три файла страницы на этом этапе не создаются. Следующий шаг — реализация прототипа после отдельной команды пользователя.
